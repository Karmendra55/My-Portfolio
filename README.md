## Installation

Clone the repository:

```bash
git clone https://github.com/Karmendra55/My-Portfolio.git
```

Navigate to the project:

```bash
cd My-Portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
